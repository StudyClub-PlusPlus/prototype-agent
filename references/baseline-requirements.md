# 웹 기본 요건 (Baseline)

> 모든 Ingest 는 이 목록을 대조해 **누락분을 Story 후보로 자동 보충**한다 (`ingest-reconcile.md §2.5`).
> 비적용 결정은 사용자 확인 후 P2 강등 또는 `폐기` 처리하고 `_HISTORY.md` 에 사유를 남긴다.
> "우리 서비스엔 해당 없음"도 **명시적 결정**이어야 한다. 침묵은 누락과 구분되지 않는다.

## B1. 계정·인증
- [ ] 로그인 / 로그아웃
- [ ] 세션 만료 시 동작 (작업 중 데이터 보존)
- [ ] 권한 없는 화면 접근 시 처리
- [ ] 로그인 후 원래 가려던 곳으로 복귀

## B2. 정보 구조·탐색
- [ ] 전 화면에서 현재 위치를 알 수 있는가
- [ ] 목록 → 상세 → 뒤로가기가 상태를 잃지 않는가
- [ ] 필터·검색·탭이 URL 에 반영되는가 (공유·새로고침)
- [ ] 404 / 권한없음 / 서버오류 화면

## B3. 목록·데이터 표시
- [ ] 로딩 상태
- [ ] 빈 상태 (첫 사용 · 검색 결과 없음 구분)
- [ ] 오류 상태 + 재시도
- [ ] 정렬·페이지네이션(또는 더보기) 기준

## B4. 입력·폼
- [ ] 필수/선택 구분과 검증 문구
- [ ] 서버 검증 (클라이언트 검증만으로 끝내지 않음)
- [ ] 중복 제출 방지
- [ ] 작성 중 이탈 경고 또는 임시 보존

## B5. 접근성
- [ ] 키보드만으로 전 기능 조작
- [ ] 색 대비 4.5:1 이상 (큰 글씨 3:1)
- [ ] 색만으로 정보를 전달하지 않음 (상태에 텍스트 라벨 병행)
- [ ] 이미지 대체 텍스트, 폼 라벨 연결
- [ ] 모달 포커스 가둠·Esc 닫기

## B6. 반응형
- [ ] 모바일 폭에서 가로 스크롤이 생기지 않음
- [ ] 터치 타깃 최소 44px
- [ ] 표·긴 콘텐츠의 모바일 대응

## B7. 성능
- [ ] 첫 화면 렌더 기준치와 측정 방법
- [ ] 이미지 최적화·지연 로딩
- [ ] 목록 크기 상한

## B8. SEO·공유
- [ ] 페이지별 title·description
- [ ] 공유 미리보기(OG) 이미지·문구
- [ ] 정적/동적 렌더 선택 근거

## B9. 국제화
- [ ] 문구 하드코딩 여부
- [ ] 지원 언어와 기본 언어
- [ ] 날짜·숫자·통화 형식

## B10. 개인정보·보안
- [ ] 수집하는 개인정보 항목과 목적
- [ ] 보관 기간·파기
- [ ] 로그·에러 리포트에 민감정보 미포함
- [ ] 권한 검증이 서버에 존재

## B11. 운영
- [ ] 관리자가 콘텐츠를 직접 고칠 수 있는가 (배포 없이)
- [ ] 오류 발생을 운영자가 알 수 있는가
- [ ] 주요 지표를 볼 수 있는가

## B12. 상태 일관성
- [ ] 같은 상태를 여러 화면이 **같은 규칙**으로 판정하는가 (판정 로직 단일 정의)
- [ ] 목록의 상태 표기와 상세의 상태 표기가 어긋나지 않는가
