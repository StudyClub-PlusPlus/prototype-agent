# 완전 종결 루프 (잔여 0 보장)

> 3중 게이트의 마지막. **잔여를 보고만 하고 종료하는 패턴을 금지**한다.
> 잔여가 있으면 사용자 확인 없이 본인이 다음 작업을 발주해 처리하고, 잔여 0 에 도달해야 종료 보고를 낸다.

## 1. 잔여 10개 축

| 축 | 내용 | 확인 방법 |
|---|---|---|
| **R1** | `_HISTORY.md` 영향 하위 플래그가 ☐ 로 남음 | 파일 스캔 |
| **R2** | Epic 또는 IA 미매핑 Story | `stories.md` 컬럼 빈칸 |
| **R3** | Baseline 미커버 항목 | `baseline-requirements.md` 대조 |
| **R4** | 변경 계획에 있었는데 안 한 항목 | 계획 ↔ 결과 대조 |
| **R5** | 검증 루프 미통과 (HIGH·MED 잔존) | 마지막 리뷰 결과 |
| **R6** | PR 미제출 | git 상태 |
| **R7** | `_HISTORY.md` 엔트리 누락 | 변경 ↔ 원장 대조 |
| **R8** | IA 커버리지 / Function 재사용 미정합 | `ia.md`·FS 스캔 |
| **R9** | Orphan Story (Epic 부모 없음) | `stories.md` |
| **R10** | 정규문장 규약 위반 또는 PRD 미작성 Story | 전수 스캔 |

## 2. 자동 재발주

잔여 항목별로 **적절한 모드로 본인이 디스패치**한다. 메뉴 질문 금지.

| 잔여 | 발주할 모드 |
|---|---|
| R1·R4·R7 | 해당 문서 갱신 후 원장 기록 |
| R2·R9 | Ingest (Epic·IA 매핑) |
| R3 | Baseline Coverage Pass |
| R5 | 수정 후 검증 루프 재실행 |
| R8 | FS Reconcile |
| R10 | 정규문장 정정 / PRD 작성 |

## 3. 보존 잔여 (예외)

아래 **둘만** 잔여에서 제외한다. `_HISTORY.md` 에 사유를 기록한다.

- **외부 차단**: 이 세션에서 해결 불가 (권한 부재, 외부 응답 대기, 미제공 자료)
- **사용자 명시 보류**: 사용자가 "그건 나중에"라고 말한 것

> **"사유를 적었으니 ☑" 는 회피다.** 본 세션에서 디스패치 가능한 모드(Ingest·PRD·검증)로
> 처리할 수 있는 항목은 전부 처리한다. cascade 플래그·미매핑은 보존 잔여가 아니다.

## 4. 블로킹 예외

사용자 결정이 반드시 필요한 항목만 **1회·일괄** 질문하고, 답을 받으면 즉시 재진입한다.

## 5. 종료 조건

**10개 축이 동시에 ∅** 일 때만 종료 보고 출력이 허용된다.

## 6. 종료 보고 금지 표현

아래 표현이 보고문에 들어가면 **출력하지 말고 그 작업을 직접 수행한 뒤** 다시 종결 게이트로 진입한다.

- "다음 단계 후보"
- "요청 시 진행"
- "원하시면 …"
- "이어서 …할까요"
- "…을 진행하시려면"
- 후속 작업 불릿 나열

보고는 **사실 요약·발견·플래그**만 담는다.
