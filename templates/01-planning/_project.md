# 프로젝트 메타

> placeholder(`<...>`)를 채우면 부트스트랩 완료. 이후 에이전트는 이 값을 다시 묻지 않는다.

## 1. 제품

| 항목 | 값 |
|---|---|
| 제품명 | `<제품명>` |
| 한 줄 정의 | `<누구에게 무엇을 제공하는 웹 서비스인가>` |
| 사용자 사이트 | `<URL 또는 미정>` |
| 운영 콘솔 | `<URL 또는 미정>` |

## 2. 저장소

| 항목 | 값 |
|---|---|
| 기본 브랜치 | `<main>` |
| 레포 공개 여부 | `<public / private>` |

> **public 이면** `01-planning/` 전체가 공개된다. 내부 전용 정보(내부 URL·고객 실명·계약 조건·
> 미공개 로드맵)를 본문에 넣지 않는다.

## 3. Actor 매핑

표준 8종을 그대로 쓰거나, 프로젝트 고유 역할명으로 치환한다.
치환하면 **치환명만** 문서에 쓴다(표준명 병기 금지).

| 표준 | 이 프로젝트에서 부르는 이름 |
|---|---|
| ACT-01 방문자 | `<방문자>` |
| ACT-02 회원 | `<회원>` |
| ACT-03 신청자 | `<신청자>` |
| ACT-04 콘텐츠 편집자 | `<편집자>` |
| ACT-05 운영자 | `<운영자>` |
| ACT-06 관리자 | `<관리자>` |
| ACT-07 개발자 | `<개발자>` |
| ACT-08 비회원 구매자 | `<해당 없음이면 비움>` |
